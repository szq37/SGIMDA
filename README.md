# SGIMDA
Robust miRNA–Disease Association Prediction via Source-Specific Mesoscale Topology Modeling

Requirements：
Python 3.8.18
PyTorch 2.0.0
DGL 2.0.0+cu117
TorchData 0.6.0
NumPy 1.22.0
Pandas 1.5.3
Scikit-learn 1.3.2
SciPy 1.10.1
NetworkX 2.8.8

Datasets：
SGIMDA utilizes the following two benchmark datasets:HMDD v4.0 and miRBase.
